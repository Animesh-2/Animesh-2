- 💻 **Software Development Engineer-1** at **NUVO AI**, engineering real-time clinical AI platforms and high-performance web systems.
- 🩺 **Medical Imaging & 3D WebGL:** Architecting web-based DICOM/NIfTI diagnostic viewers with **Cornerstone3D**, **OHIF Viewer**, and **DICOMweb (WADO-RS/QIDO-RS)**.
